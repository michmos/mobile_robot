## Instructions
* write the todo to the file {PROJECT_DIR}/TODO.md
* use the following format: - [ ] {This is some todo text}
* be concise about the todo but add filenames and line numbers if applicable
* scan the TODO.md file and:
  * delete outdated todos
  * bundle similiar todos in a paragraph with a descriptive markdown header
* in the chat, just mention how many todos you added, and point out if one of those should be handled immediately
